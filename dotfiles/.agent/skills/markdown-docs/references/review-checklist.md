# Markdown レビューチェックリスト

SKILL.md「レビュー」で通読を終えたあとに開く。報告形式は SKILL.md を正とする。

## 構成

- [ ] H1 が 1 つで、階層の飛びがない
- [ ] 見出しが内容を表し、同階層で並列
- [ ] 節の順序が読者の行動順(前提、導入、使い方、詳細、参考)になっている
- [ ] 重複する節、不要な前置きがない
- [ ] 前提条件と手順の抜け(暗黙のステップ)がない

## 記法

- [ ] コードフェンスに言語がある
- [ ] コマンド、パス、API 名、設定キーが backtick 付きで原文どおり
- [ ] リスト記号、強調、表の列数が揃っている
- [ ] 表が比較・一覧として妥当で、単純な列挙になっていない

## 文章

- [ ] 一文が長すぎない(60 文字目安)、主語と述語が対応する
- [ ] 専門用語に初出の説明がある
- [ ] 文体、用語、人称、時制、日付形式が統一されている
- [ ] 誤字脱字がない

## リンク・画像

- [ ] 相対パス、見出しアンカーが実在する
- [ ] リンクテキストが具体的(「こちら」を避ける)
- [ ] 画像に内容を表す alt がある(装飾画像は空の alt)

## 対象外

- 数値、出典、コードの正しさは本 checklist で判定しない。必要なら依頼者に別途確認を提案する。
